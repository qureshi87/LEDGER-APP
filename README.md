# Stock Ledger App

A lightweight stock ledger app for tracking stock received from vendors, issued to people, and the remaining balance in stock.

## Features

- Record items received from vendors
- Record items issued to a person or team
- Track stock adjustments
- View live remaining stock and inventory value
- Review all ledger entries with vendor/person details
- Keep data saved in the browser using localStorage
- Load demo data instantly to explore the app

## Open locally

Open the project folder and open the HTML file in a browser, or serve it with any static file server.

## Files

- `index.html` — app layout
- `styles.css` — styling
- `app.js` — ledger logic and local storage
